## ✨ Features

- 🧠 **AI Suggestions (Gemini)**: Get vocabulary-enhancing and creative suggestions to enrich your entries.
- 📅 **Email Reminders**: Never forget to write—receive daily/weekly gentle nudges.
- 📔 **Memory Timeline**: Revisit and reflect on your past entries effortlessly.
- 🧩 **Minimal & Intuitive UI**: Built to reduce friction and encourage consistent journaling.
- 🔒 **Private & Secure**: Your thoughts, your space.

## 🛠 Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas
- **AI Suggestions**: Google Gemini API (or compatible AI engine)
- **Email Services**: Nodemailer / SMTP
- **Hosting**: Vercel / Netlify

## 🚀 Getting Started

To run Journizz locally:

```bash
# Clone the repo
git clone https://github.com/yourusername/journizz.git
cd journizz

# Install dependencies
npm install

# Set environment variables
# Create a .env file with your MongoDB URI, API keys, etc.

# Run the development server
npm start
